# Pokémon Smaragd Hroen is Pokémon Emerald...maar met een ludieke West-Vlaamse twist

Dit is een hobbyvertaling van Pokémon Emerald. Het is een halfserieuze West-Vlaamse vertaling met een serieuze dosis humor. Het oorspronkelijke verhaal en de typisch 'luchtige' Pokémon-sfeer is nog altijd aanwezig. Pokémon Emerald is m'n favoriet spel en ik heb dit gedaan omdat ik van het spel hou en het een leuke vertaalopdracht vond.

Het is nog lang niet af wel.

Vooruitgang:
✓ Littleroot
✓ Olddale
✓ Petalburg
✓ Route 101-109
Nu aan het vertalen: Rustboro, Dewford


Ik baseer mij op de decompilation van Emerald van [Pret](https://github.com/pret/pokeemerald) en specifiek Resetes12's versie [Modern Emerald](https://github.com/resetes12/pokeemerald) die een heleboel QOL verbeteringen aanbiedt. Je hebt devkitARM nodig als je zelf wilt compileren.
